AICode DeepSeek BYOK (do this once in the UI — do not put the API key in git)

1. Open the AICode sidebar in Cursor → Settings → OpenAI-compatible
2. Base URL: https://api.deepseek.com
   (If the form expects an OpenAI SDK-style root, use https://api.deepseek.com/v1)
3. Paste your DeepSeek API key from https://platform.deepseek.com
4. Register models:
   - deepseek-v4-pro  (default for specs / coding)
   - deepseek-v4-flash (fast / cheap)
5. Smoke test: + New Chat → “Where is idle destroy gated?”

The key is stored only in Cursor globalStorage for joelabenhaim.aicode-ja.
Never commit keys into .env, project-settings.json, or this file.
