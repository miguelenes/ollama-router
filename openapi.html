ollama-router admin API (0.1.0)

Download OpenAPI specification:

License: Apache-2.0

Admin surface under /router/v1/*. Every endpoint requires Authorization: Bearer $OLLAMA_ROUTER_ADMIN_TOKEN. There is no default secret: when the token is unset, the whole admin API fails closed with 403.

Unauthenticated endpoints: GET /healthz, GET /readyz, GET /metrics.

Sensitivity: the router never logs request bodies, prompts, share tokens, or the admin bearer. This document uses env-var placeholders only.
